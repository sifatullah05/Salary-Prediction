
# 💼 Predicting Employee Salaries using Regression Algorithms in Scikit-learn

## 🎯 Objective
This project predicts employee salaries using machine learning. It cleans the data, explores important features, and builds models like Linear Regression, Decision Tree, Random Forest, and KNN to find the best and most accurate salary prediction model.

---

## 📄 Overview
This project aims to predict employee salaries based on factors such as **Age**, **Years of Experience**, **Education Level**, **Gender**, and **Job Title**.  
It covers all key machine learning steps — from data cleaning and visualization to feature engineering and model evaluation — using Scikit-learn regression algorithms.

---

## ⚙️ Project Workflow
1. **Data Loading** — Importing and exploring the dataset  
2. **Data Cleaning** — Handling missing values and duplicates  
3. **Exploratory Data Analysis (EDA)** — Visualizing patterns and relationships  
4. **Feature Engineering** — Encoding categorical data and removing outliers  
5. **Model Building** — Applying various regression models  
6. **Model Evaluation** — Comparing performance using R² Score, MAE, and MSE  
7. **Result Summary** — Selecting the best model for prediction

---

## 🧠 Algorithms Used
- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor  
- K-Nearest Neighbors (KNN) Regressor  

---

## 📊 Model Performance

| Model                     | R² Score (%) |
|----------------------------|--------------|
| Linear Regression          | 93.47 |
| Decision Tree Regressor    | 91.74 |
| **Random Forest Regressor**| **95.78 ✅ (Best)** |
| KNeighbors Regressor       | 92.71 |

---

## 🏁 Conclusion
Among all models tested, the **Random Forest Regressor** performed best with an R² score of **95.78%**, making it the most reliable model for salary prediction.  
The model can be further improved by tuning hyperparameters or using advanced ensemble methods.
